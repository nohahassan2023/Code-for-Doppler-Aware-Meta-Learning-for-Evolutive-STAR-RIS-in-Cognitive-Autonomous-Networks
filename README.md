Meta2L: Doppler-Aware Meta-Learning for Evolutive STAR-RIS

Simulation code for the paper:

N. Hassan, M. Yaseen, X. Fernando, and H. Yanikomeroglu, “Doppler-Aware Meta-Learning for Evolutive STAR-RIS in Cognitive Autonomous Networks,” submitted to IEEE Journal of Selected Topics in Signal Processing.

This repository contains the simulation code used to evaluate Meta2L and the baselines considered in the paper. The simulations model a multi-AP, multi-user STAR-RIS system with Gauss–Markov channel evolution. The scripts listed below generate the figures and tables reported in the results section.

Requirements

Python 3.10 or later is required. The required packages are 
numpy>=1.24
scipy>=1.10
torch>=2.0
matplotlib>=3.7


All simulations run on a CPU. No GPU is required.

Reproducing the Results

The figures are saved in output_figures/.

Paper resultCommandSum-rate versus episode, adaptation speed, and ablation studypython META2L_MATCHING_PAPER.pyLearned β versus velocitypython META2L_LEARN_BETA.py followed by python plot_fig2.pyStateful versus memoryless under impairments, sum-rate versus settling delay, gradient steps, scalability, and sensitivity to λpython META2L_SENSITIVITY4.pyFPGA critical-path latencypython plot_fig5.pyTemporal-reuse baselines and Meta2L-C (Table VIII)python META2L_R3_BASELINES.py

The main system parameters are defined in the SystemParams class near the top of each simulator. The number of trials and episodes can be adjusted near the bottom of each script. For a quick test, these values can be reduced before running the full simulations.

Randomness and Reproducibility

The NumPy and PyTorch random seeds are fixed at the beginning of each trial. As a result, running the code with the same software versions should produce the same results. Minor numerical differences may occur with different library versions or hardware.
